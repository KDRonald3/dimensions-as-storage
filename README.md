# Dimensions as storage: the results page

**The page: https://kdronald3.github.io/dimensions-as-storage/**

Preliminary results on a simple question: do small transformers store facts in the space their
words live in? At the same parameter count, the model with more dimensions knew more facts.

**The project itself (code, the plan written before each experiment, the reports and the result
of every training run) is open source: https://github.com/KDRonald3/air**

This repository holds only the page (`docs/index.html` and its pictures).
