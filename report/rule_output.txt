THE AGREED DECISION RULE (fixed before any experiment was run)
For one model width, at one usage and one number of seasons, the hypothesis "clearly holds" when, in
    at least 2 seeds, all of these are true:
  (a) the width scores 95 or more on the 16-animal language (the score is facts known, 0 to 100);
  (b) on some larger vocabulary its run ended by plateau and scored at least 10 points below its own
      16-animal score;
  (c) on that vocabulary the next width up, with the same seed and so the same training sets, scores
      at least 10 points higher.
A run that ended by budget is NOT FINISHED and can never satisfy (b).
Nor can a run that was given a fixed number of sets (--fixed-sets): the stopping rule was never
    asked.
The next width up of a width is 2 times that width (8 for width 4). No other width can stand in for
    it.
A plateau is a plateau under the stopping rule of train.py with its agreed settings (solved_at 97,
    flat_points 2, flat_gap 0.05, flat_gap_bits 0.002, min_sightings 400, min_steps 2000, started_at
    5). It is never called while a run knows fewer than 5 facts out of 100, so a run that never
    begins to learn facts ends by budget and cannot satisfy (b).
The rule is applied only to a group of runs that were all trained the same way and under that
    stopping rule.
